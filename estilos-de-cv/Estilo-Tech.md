**Estilo Tech Resume**

*El currículum del software engineer pragmático: tech stack denso, projects, GitHub, métricas de impacto técnico balanceadas con context business*

# **Industrias donde funciona mejor**

Tech Resume está concentrated en tech industry mainstream. Effective across spectrum from modern startup to traditional corporate tech.

### **Industrias de alta compatibilidad**

* **BigTech non-FAANG**

* **Mid-market enterprise tech**

* **Fintech mainstream**

* **Healthtech mainstream**

* **Enterprise SaaS**

* **Ad tech, marketing tech**

### **Compatibilidad media**

* **FAANG / pure Silicon Valley**

* **Modern scaleups**

* **Traditional corporates con tech departments**

# **Estructura exacta del CV**

La estructura Tech Resume es similar a Silicon Valley pero con slight adaptations: more conventional formatting, Tech Stack section more prominent, Education position varies (top for new grads, after Experience for senior), Projects section optional but recommended.

### **Orden canónico de secciones**

1. 1\. Cabecera: nombre, contact (email, phone optional, LinkedIn URL, GitHub URL, personal website if relevant), location (City, State or City, Country). Sin foto, sin DOB.

2. 2\. Summary opcional (2-3 líneas): para mid+ candidates, brief positioning statement. Para new grads, opcional.

3. 3\. Tech Stack / Technical Skills: prominent section, categorizada. Languages, Frameworks, Cloud/Infrastructure, Databases, Tools, Methodologies.

4. 4\. Experience: cronología inversa, cada role con company, role, dates, location, bullets de achievements técnicos cuantificados cuando posible.

5. 5\. Education (position varies): for new grads, before Experience; for senior, after Experience. Includes university, degree, year, GPA if 3.5+, relevant coursework for new grads.

6. 6\. Projects (opcional pero recomendado): personal projects, hackathons, bootcamp capstones, open-source contributions. Each con tech stack, link to GitHub or live demo, brief description.

7. 7\. Certifications (opcional): AWS, Azure, GCP, Kubernetes, security certifications.

8. 8\. Awards / Honors (opcional): Olimpiadas programación (ACM ICPC, IOI), hackathon wins, tech-adjacent awards.

### **Jerarquía visual**

Hierarchy: Tech Stack y Experience are co-prominent. Section headers consistent. Bullets concise.

### **Longitud y densidad**

New grad / Junior: 1 página estricta

Mid (3-7 años): 1 página densa, occasionally 1.5

Senior (7-12 años): 1-2 páginas

Staff+ / EM (12+ años): 2 páginas

# **Secciones obligatorias, opcionales y prohibidas**

### **Obligatorias**

* **Cabecera con contact y digital identity:** Email, LinkedIn, GitHub, location. Phone optional in remote-first era. Personal website si relevant.

* **Tech Stack / Technical Skills categorizada:** Languages, Frameworks/Libraries, Cloud/Infra, Databases, Tools. Specific y current.

* **Experience con tech focus:** Cada role con bullets describing technical work, technologies used, impact. Bullets concise pero substantive.

* **Education:** University, degree, graduation year. GPA si destacable. For new grads more prominent; for senior more compact.

### **Opcionales (según contexto)**

* **Summary / Profile:** Brief positioning para mid+ candidates. Skip for new grads typically.

* **Projects:** Personal projects, bootcamp capstones, hackathons, open source. Especially valuable for new grads y career-changers.

* **Certifications:** AWS Solutions Architect Associate/Professional, GCP Professional Cloud Architect, Azure Solutions Architect Expert, Kubernetes (CKA, CKAD), security certs.

* **Awards:** Hackathon wins, programming competition rankings (Codeforces rating, ACM ICPC, IOI medals), Kaggle medals.

* **Open source contributions:** If significant: maintainer roles, popular packages, notable PRs to major projects.

* **Speaking / Writing:** If candidate has tech blog with traction, conference talks, technical podcasts.

* **Languages:** Programming languages already in Tech Stack; this is human languages, relevant for international roles.

### **Prohibidas o desaconsejadas**

* **Foto, DOB, marital status (USA market):** Inappropriate.

* **Skill bars o ratings 80%/90%:** Anti-pattern.

* **Objective genérico:** Replaced by Summary or omitted.

* **Soft skills genéricos sin evidencia:** 'Team player', 'good communicator'. Inútiles.

* **Listing every technology touched in 8 years:** Tech Stack should be technologies you'd handle confidently in interview, not exposure.

* **References available upon request:** Asumido.

# **Características visuales y diseño**

Visualmente Tech Resume es clean, professional, tech-aware sin being aesthetically distinctive. Sans-serif moderna, single column, mínima decoración.

### **Layout y columnas**

Single column estricto

Cabecera mínima 2-3 líneas

Section headers prominent (12-13pt bold or uppercase tracked)

Bullets simples (•) en typography neutra

Two-column information per line common: 'Company / Role / Location / Dates'

### **Espaciado, márgenes y whitespace**

Interlineado 1.15-1.25

Espaciado entre sections 8-12pt

Espaciado entre items 4-6pt

Márgenes 0.5-0.75 inch (US Letter)

### **Iconografía y elementos gráficos**

Iconos minimal o ausentes en cabecera

Sin iconos decorativos en bullets ni sections

### **Densidad de información y balance visual**

Densidad informativa moderada-alta

Tech keywords integrados naturalmente

Whitespace funcional

# **Sistema tipográfico**

Typography Tech Resume usa sans-serif moderna versátil. Mainstream choices: Calibri (ATS-safe default), Arial, Inter, Helvetica Neue, Roboto, Source Sans Pro, IBM Plex Sans.

### **Tipografías recomendadas**

* **Calibri:** Microsoft default. Universal compatibility. Body 11pt. Default safe.

* **Inter:** Modern excellent. Body 10-11pt. Comunica modern tech awareness.

* **Arial:** Universal sans-serif. Body 10-11pt. ATS-safest.

* **Helvetica Neue / Helvetica:** Classic modernist. Body 10-11pt. Profesional neutral.

* **Roboto:** Google ecosystem default. Body 10-11pt. Slight technical signaling.

* **IBM Plex Sans:** IBM design system. Body 10-11pt. Professional \+ technical.

* **Source Sans Pro:** Adobe open source. Body 10-11pt. Professional y modern.

### **Jerarquía de tamaños**

Name: 16-22pt

Section headers: 11-13pt uppercase or bold

Company / Role: 11pt bold

Body bullets: 10-11pt

Dates / metadata: 10pt regular

### **Tipografías a evitar**

Times New Roman: dated for tech context

Comic Sans, decorative: descalificantes

Custom display fonts not embedded

Multiple font families mixed

# **Uso del color**

Color Tech Resume es minimal: black/dark gray para texto, opcional one accent color.

### **Paletas recomendadas**

* **Pure achromatic:** Black/dark gray text. No accent. Maximally safe.

* **Achromatic \+ dark blue accent:** Body negro, name y section headers en dark navy. Most common Tech Resume palette.

* **Achromatic \+ dark gray accent:** Body negro, name y headers en dark gray (\#404040). Subtle differentiation.

# **Estilo de redacción**

Writing Tech Resume es professional technical sans being too informal Silicon Valley o too formal Harvard. Verbs técnicos, métricas cuando posible, balance technical y business context.

### **Tono y voz**

Tono professional tech-aware. Confident pero not aggressive autopromocional. Direct y specific.

Voz primera persona implícita, pasado simple para previous, present para current.

### **Verbos de acción y estructura de frases**

Building: Built, Developed, Designed, Implemented, Created, Engineered, Architected (less aggressive than 'Spearheaded')

Shipping: Shipped, Launched, Released, Deployed, Delivered

Scaling/Optimizing: Scaled, Optimized, Reduced, Improved, Migrated, Refactored

Leading: Led, Coordinated, Mentored, Collaborated

Avoid: 'Spearheaded' (over-corporate for tech), 'Drove' overuse

### **Uso de métricas, KPIs y storytelling**

Performance: 'Reduced API response time from 800ms to 120ms', 'Increased throughput 5x'

Scale: 'Service handling 12M requests/day', 'Database serving 500GB+ active'

Reliability: 'Maintained 99.9% uptime over 18 months'

Business: 'Feature contributing to 8% increase in user retention'

Adoption: 'Library used by 23 internal teams'

Cost: 'Reduced AWS spend by $180K/year'

# **Compatibilidad ATS**

Tech Resume bien construido is highly ATS-friendly. Conventional structure, semantic clarity, technical keywords. Excellent compatibility across modern y legacy ATS.

### **Elementos que mejoran el parsing**

* Tech Stack section explicit

* Standard headers (Experience, Education, Skills)

* Tech keywords matching job description

* Acronyms standardized (AWS, GCP, REST, GraphQL, gRPC)

* Dates consistent

* Company names spelled out

* PDF generated from text source

### **Elementos que rompen ATS**

* Multi-column layouts decorative

* Tables for skills

* Custom fonts not embedded

* Iconos as text substitutes
